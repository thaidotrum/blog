# Kiến Thức Mỗi Ngày

Một trang blog tĩnh đơn giản để mình ghi chép và chia sẻ kiến thức.

## Cách sử dụng

1. Mở file `index.html` bằng trình duyệt để xem giao diện blog.
2. Các bài viết mẫu được lưu trong `assets/scripts.js`. Bạn có thể chỉnh sửa hoặc
   bổ sung nội dung mới bằng cách cập nhật danh sách `posts`.
3. Tùy chỉnh giao diện bằng cách sửa file `assets/styles.css`.

## Tính năng nổi bật

- Hero giới thiệu ngắn gọn mục tiêu của blog.
- Các chủ đề chính giúp định hướng nội dung.
- Danh sách bài viết mới nhất có thể lọc theo chủ đề.
- Form đăng ký nhận bản tin với thông báo cảm ơn.

Chúc bạn viết blog vui vẻ! ✍️
